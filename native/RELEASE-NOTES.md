# 서버 주소 변경 · 모코코.웹.한국

- 접속기 3.0.1의 기본 게임 주소를 `모코코.웹.한국`으로 변경했습니다.
- 기존 3.0 접속기는 패치 점검 또는 게임 시작 시 서명된 업데이트를 받아 자동으로 교체됩니다.
- 예전 기본 주소가 저장되어 있으면 새 주소로 옮깁니다. 직접 설정한 다른 서버와 포트는 유지합니다.
- 계정, 인벤토리, 게임 설정은 이번 주소 변경 대상에 포함되지 않습니다.
- 의상실 등 기존 게임 패치는 그대로 유지합니다. 위키의 접속 안내도 새 주소로 바뀝니다.

검증: 주소 전환 및 회귀 검사 66개, 격리된 실제 접속기 준비 과정 7개 통과. 패키지의 서명과 파일 해시를 확인했습니다. 이번 주소 변경에서 실제 로그인·게임 화면 검사는 다시 수행하지 않았습니다.

기존 3.0 사용자는 파일을 다시 받지 않고 접속기의 **패치 점검**을 누르세요. 접속기가 다시 열리면 서버 주소가 `모코코.웹.한국`인지 확인한 뒤 게임을 시작하세요.
