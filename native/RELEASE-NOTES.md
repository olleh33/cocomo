게임 콘텐츠 패치 3.0.7

흰색 콘크리트 계단이 일반 흰색 콘크리트와 다른 색으로 보이던 문제를 수정했습니다. 계단을 일반 지형과 같은 방식으로 표시해 질감·조명·그림자가 자연스럽게 이어집니다. 이미 설치한 계단에도 적용되며 다시 설치할 필요가 없습니다. 일반 석영 계단은 바뀌지 않습니다.

격리 서버에서 설치·방향·모서리·회수·땅 보호·저장 및 재불러오기 419개 검사와 외형 정보 전송 검사를 통과했습니다. 실제 BSL 셰이더 화면에서 낮·밤 및 청크 새로고침을 확인했습니다.

게임을 완전히 종료하고 기존 자체 접속기에서 다시 실행하면 자동 업데이트됩니다. 접속기 파일을 다시 받을 필요는 없습니다. 실행 파일은 3.0.1을 유지하고 게임 콘텐츠만 3.0.7로 업데이트합니다.
