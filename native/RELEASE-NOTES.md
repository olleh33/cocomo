우리 서버 전용 접속기 3.0이에요.

- GitHub에서 모드·리소스팩·한국어 UI를 각각 내려받아요. 패치 목록에 파일 전체를 넣던 방식을 바꿔 목록이 약 3.6KB로 줄었어요.
- 서명과 SHA-256이 일치하는 파일만 적용해요. 접속기 자체 업데이트도 지원해요.
- 기존 2.0 폴더에 압축을 풀어 덮어쓰면 data 폴더의 계정·단축키·게임 설정을 유지해요. 게임과 접속기를 먼저 종료하세요.
- 처음 사용하는 분은 계정 연결을 눌러 공식 Prism에서 Microsoft 계정을 연결하세요.

다운로드할 파일은 `mokokoko-launcher-3.0.0.zip`이에요. 나머지 파일은 접속기가 자동으로 받아요.
