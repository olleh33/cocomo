게임 콘텐츠 패치 3.0.3

가구 133종·건축 블록 58종을 일반 돈으로 구매하는 가구·건축 상인과 전용 GUI를 추가했습니다. 가구는 3,000~20,000원, 건축 블록은 개당 100~250원입니다. 새 치장 76종을 추가해 총 104종을 의상실에서 이용할 수 있습니다. 의상 하나당 치장 티켓 2장, NPC를 통한 구매·착용·해제 규칙은 유지합니다. 의상실에 풍선 탭과 페이지 이동을 추가했습니다.

J 지도에서 땅 이름은 소유자의 한글 닉네임으로 표시됩니다. 공유받은 땅도 원래 소유자의 이름으로 표시됩니다.

게임을 완전히 종료하고 기존 접속기에서 다시 시작하면 자동 업데이트됩니다. 접속기 파일을 다시 받을 필요가 없습니다.
