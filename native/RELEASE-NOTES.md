게임 콘텐츠 패치 3.0.8

마을 북쪽 모코코 공용 주방에 항상 불이 켜진 요리 솥 8개를 추가합니다. 재료를 들고 솥을 우클릭하면 1개씩 들어가고, 알맞은 마지막 재료를 넣으면 자동으로 요리가 시작됩니다. 레시피 GUI는 보기 전용입니다.

기본 요리 5종과 요리 종류·낚시·던전으로 발견하는 추가 요리 5종을 준비했습니다. 음식은 먹어서 효과를 받거나 주방 요리사에게 판매할 수 있습니다. 일반·은별·금별 재료와 완성 요리를 구분합니다.

잘못된 재료는 소모하지 않고, 완성품은 솥을 사용한 사람만 받습니다. 미수령 요리와 레시피 책은 요리사 보관함에서 받을 수 있습니다.

Minecraft를 완전히 종료한 뒤 기존 자체 접속기에서 게임을 시작해 자동 업데이트하세요. 접속기 파일을 다시 받을 필요는 없습니다. 실행 파일 3.0.1 유지, 게임 콘텐츠 3.0.8 및 전용 화면 1.3.5 업데이트입니다.
