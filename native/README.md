# 뫀코코의 마을 접속기 3.0

Minecraft Java 1.21.8 전용 Windows 접속기예요. 기존 마을 UI와 공식 Prism 계정 연결 흐름을 유지하면서 GitHub Releases로 업데이트를 배포해요.

게임 시작 → 접속기 새 버전 확인 → 서명 검증 → 필요한 파일만 내려받기 → 게임 실행 순서로 동작해요.

- 모드·번역을 JSON 안에 넣지 않고 파일 주소·크기·SHA-256만 기록해요. 현재 패치 목록은 약 3.6KB예요.
- 리소스팩·자체 모드·한국어 UI는 운영자가 서명한 이 저장소의 릴리스에서 받아요. 일반 모드는 공식 Modrinth CDN을 사용해요.
- 기존 2.0의 서명된 패치도 읽을 수 있어요. 기존 폴더에서 업데이트하면 계정·단축키·개인 설정을 유지해요.
- 잘못된 서명, 다른 저장소 주소, 손상된 파일, 경로 이탈, 임의 계정 파일 변경을 거부해요.
- 로그인은 공식 Prism에서 진행해요. GitHub 로그인이나 비밀번호가 필요하지 않아요.

예를 들어 MokoKeys가 70KB에서 1MB로 커져도 패치 목록에는 주소와 검증 정보만 들어가므로 목록 크기는 거의 늘지 않아요.

빌드는 Windows에서 .NET SDK 10.0.401과 Python 3.12 이상으로 `python native/scripts/build.py`를 실행해요. 생성된 `native/bin/LauncherTests.exe`에 비어 있는 테스트 폴더 경로를 전달하면 회귀 검사를 실행해요.

서명 개인키·계정 데이터는 저장소에 넣지 않아요. 서버 운영자는 검증한 릴리스 파일을 별도로 서명하며, GitHub Actions는 해시가 일치하는 파일만 릴리스에 게시해요.
