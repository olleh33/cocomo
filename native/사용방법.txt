뫀코코의 마을 접속기 3.0.1

서버 주소: 모코코.웹.한국 (기본 포트 25565)
3.0 접속기는 패치 점검 후 자동으로 3.0.1로 업데이트돼요.
기존 기본 서버 주소도 새 주소로 바뀌며, 따로 입력한 개인 주소는 유지돼요.

처음 설치
1. ZIP 압축을 일반 폴더에 풀고 뫀코코접속기.exe를 실행하세요.
2. 계정 연결을 눌러 공식 Prism에서 Microsoft 계정을 연결하세요.
3. 게임 시작을 누르면 GitHub 패치 확인 후 서버에 접속해요.

2.0에서 업데이트
게임과 접속기를 종료한 뒤, 기존 접속기 폴더에 이 ZIP의 파일을 덮어쓰세요.
기존 data 폴더는 지우거나 옮기지 마세요. 계정·단축키·게임 설정이 유지돼요.
이 ZIP에는 계정 파일이나 data 폴더가 들어 있지 않아요.

3.0 이후
게임 시작·계정 연결·패치 점검을 누르면 새 접속기를 확인해요.
서명과 파일 검증을 통과한 새 버전은 접속기를 닫고 자동으로 교체·재실행해요.
모드와 리소스팩은 파일별로 내려받아 검증한 후 적용해요.
업데이트 중에는 프로그램을 강제로 종료하지 마세요.
